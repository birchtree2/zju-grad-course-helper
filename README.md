# 浙大研究生选课助手

适用于 `https://yjsy.zju.edu.cn/` 的 Chrome/Edge Manifest V3 扩展。

## 功能

- 通过选课系统自身的实时查询接口刷新已选/候选/容量；已选班级的人数收在助手面板的折叠区。
- 在面板中提示时间不冲突、且同课程中录取机会更高的教学班，显示课程号和教学班号。
- 打开“课程班级选择”窗口时自动着色：红色为时间冲突，绿色为不冲突，黄色为同一课程的其他教学班，蓝色为已选教学班。
- 识别秋/冬/秋冬、春/夏/春夏，以及每周、单周、双周和节次范围。
- 数据只保存在浏览器本地，不上传账号或课程信息。

## 安装

1. 打开 Chrome 的 `chrome://extensions/`（Edge 为 `edge://extensions/`）。
2. 开启右上角“开发者模式”。
3. 点击“加载已解压的扩展程序”。
4. 选择本文件夹 `zju-course-helper`。
5. 刷新研究生选课页面。右下角出现“选课助手”即安装成功。

## 使用

安装后请刷新一次“查看我的课程”页面。扩展会观察这次由站点自身发出的课程查询，随后主动查询全部课程；也可以随时点击右下角“刷新实时人数”。课程总表保持原样，建议集中显示在助手面板中。打开任意未选课程的班级列表后，教学班仍会自动着色。

人数格式固定为“已选/候选/容量”。批量刷新期间如果你打开了班级窗口，扩展会暂停后台刷新，避免干扰页面自身的班级查询。

“录取机会更高”是基于剩余容量、已选人数和候选人数的比较提示，不是学校公布的正式概率；有空余容量的教学班优先，没有空位时才显示候选估算。

## 技术说明

站点当前版本的班级查询接口为 `/py/pyKcbj/selectXsKxbjByKckId`，响应中的 `xzrs`、`hxrs`、`bjrl` 分别对应已选、候选、容量。扩展在内存中复用页面自己的同源请求头，不读取 Cookie，也不保存登录凭据。
